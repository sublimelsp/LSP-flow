Breaking changes:

- The key used to override LSP-flow settings in project settings has changed from `flow` to `LSP-flow`.
  If you use project-specific overrides for LSP-flow, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "flow": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-flow": {
                  // ...
              }
          }
      }
  }
  ```
